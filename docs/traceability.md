## Gaps

Stated rather than hidden.

| Gap | Why it is not covered | Mitigation |
|---|---|---|
| Power BI DAX measures | No automated way to execute DAX outside Power BI Desktop | `powerbi/BUILD_GUIDE.md` lists expected values for manual check against `sql/views.sql` |
| Correctness of the source data | No independent measurement exists to compare against | Out of scope, stated in the test plan |
| A value that is wrong but plausible | Range checks cannot detect it | Reconciliation (DQ-23, DQ-24) catches it if the warehouse disagrees with the raw file |
| Corruption of a raw file on disk | Both sides of the reconciliation would agree | Raw files treated as the retained source of record |
| Duplicates within a single API response | Absorbed by `transform.py` before any check runs | DEF-003, with a recommended fix |
